# Мовна вичитка

Це **окремий прохід** від редакторського. `docs/STYLE-OSINT.md` відповідає за голос
видання й структуру матеріалу — чи не проліз у текст хід нашої роботи. Цей скіл
відповідає за мову: чи це природна українська, яку приємно читати.

Порядок: спершу редакторський прохід за STYLE-OSINT, потім мовний. Інакше
вилизуватимеш речення, які потім і так викинеш.

## Крок 1. Витягти прозу

JSX читати не можна — теги розривають речення. Витягни чистий текст:

```bash
python - <<'EOF'
import io,re
p='src/app/(main)/articles/<slug>/page.tsx'
s=io.open(p,encoding='utf-8').read()
b=s[s.index('<div className="article-body">'):s.index('ДЖЕРЕЛА')]
t=re.sub(r'<[^>]*>',' ',b); t=re.sub(r'\{[^}]*\}',' ',t)
t=t.replace('&apos;',"'").replace('&nbsp;',' ')
io.open('prose.txt','w',encoding='utf-8').write(re.sub(r'\s+',' ',t))
EOF
```

## Крок 2. Автоматична діагностика

```bash
python - <<'EOF'
import io,re
t=io.open('prose.txt',encoding='utf-8').read()

kalky = r'зустрічати(ся)?\b|співпадa|у якості|в якості|на протязі|приймати участь|відноситься до|з ціллю|у зв.язку з тим|виходячи з|більш детальн|найбільш \w+ий|поставщик|відзив|міроприєм|учбов|шкода, що|згідно\s+\w+у\b|по мірі|при цьому\b|даний\b|являється|носить характер'
kancelyaryt = r'\bздійсн\w+|\bпровед\w+ня|\bвикорист\w+ня\b|\bзабезпеч\w+ня\b|\bреалізац|\bналежить до|\bмає місце|\bв цілому\b|\bз метою\b|\bшляхом\b|\bв рамках\b'
zhargon = r'вигородк|завадов|маточин|розкро|протитиск|наддув|обтічник|дифферент|планшир'

for name,pat in [('КАЛЬКИ',kalky),('КАНЦЕЛЯРИТ',kancelyaryt),('ЖАРГОН',zhargon)]:
    hits=sorted(set(m.group(0).lower() for m in re.finditer(pat,t,re.I)))
    print(f'{name}: {hits or "чисто"}')

longs=[s for s in re.split(r'(?<=[.!?])\s+',t) if len(s)>240]
print(f'\nРЕЧЕНЬ >240 знаків: {len(longs)}')
for s in longs[:15]: print('  ·',s[:150],'…')
EOF
```

## Крок 3. Що виправляти

### Кальки й русизми
Найчастіші в наших текстах: `у якості` → **як**; `на протязі` → **протягом**;
`приймати участь` → **брати участь**; `даний` → **цей**; `являється` → **є**;
`при цьому` → **водночас / до того ж**; `більш точний` → **точніший**;
`торпедопогрузочний` → **торпедонавантажувальний**.

### Жаргон без пояснення
Технічний термін при **першому** вживанні або розкривається в дужках, або
замінюється зрозумілим відповідником. Якщо термін потрібен далі — лишай і поясни
раз. Якщо трапляється один раз — заміни описом.

- `вигородка` → **відсік під** (антену, обладнання)
- `завадовий режим` → **рівень акустичних завад**
- `протитиск` вживай в однині: **з високим протитиском**, не «з великими протитисками»
- `маточина` гвинта → **втулка**
- вигадані складені слова (`ребра-гасники`) — не вигадуй, опиши: **ребра, що гасять завихрення**

### Канцелярит
Віддієслівні іменники з'їдають дію. `здійснити пуск` → **запустити**;
`провести модернізацію` → **модернізувати**; `з метою зниження шумності` →
**щоб знизити шумність**.

### Довгі речення
Понад 240 знаків майже завжди означає, що в реченні дві-три думки. Розбий.
Особливо в описових розділах, де підряд ідуть перелік, уточнення в тире й
покликання на джерело.

### Нанизування родових відмінків
«зниження рівня шумності корпусу човна проєкту» — три родових поспіль уже важко.
Перебудуй: **щоб човен шумів менше**.

### Публіцистичні штампи
`Реальність наздогнала`, `не заставили себе чекати`, `поставила крапку`,
`білі плями`, `камінь спотикання` — у фактологічному матеріалі виглядають
дешево. Прибирай або замінюй фактом.

### Терміни й одиниці
- Числа з одиницями — через нерозривний пробіл: `4&nbsp;100 к.с.`
- Діапазони — через тире без пробілів: `1987–1989`
- Лапки українські «ялинки», всередині них — „лапки-лапки“
- Апостроф — правильний символ, не `'`: **п'ять**, **об'єднання**, **інтерв'ю**, **досьє** (тут апострофа немає)
- Тире — довге `—` з пробілами, дефіс `-` тільки в складених словах

## Крок 4. Перевірка після правок

```bash
npx prettier --write "src/app/(main)/articles/<slug>/page.tsx"
npx tsc --noEmit
npm run build
```

Потім прогнати крок 2 ще раз — має бути чисто або з поясненням, чому термін
лишився.

## Чого НЕ робити

- Не спрощувати технічну суть заради гладкості. Якщо точна назва системи довга —
  вона лишається довгою.
- Не вирівнювати всі речення під одну довжину. Ритм тримається на чергуванні.
- Не замінювати цитати. Пряма мова лишається як є, навіть якщо в ній калька.
- Не чіпати назви проєктів, кораблів, установ і російські найменування систем —
  вони передаються як є, в лапках.
