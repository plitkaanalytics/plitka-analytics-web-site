# Україна готова не бити по російських НПЗ, якщо Росія не атакуватиме нашу енергетику – Зеленський

Президент Володимир Зеленський заявив, що Україна готова перестати завдавати ударів по російських НПЗ, але за умови, що росіяни перестануть бити по українській енергетичній інфраструктурі.

	 **Джерело**: [глава держави](https://t.me/V_Zelenskiy_official/21313) в Telegram

	 **Пряма мова Зеленського**: "Реальна причина війни в Європі – Росія, і тільки вона. Вже сьогодні реально зупинити удари по енергетиці, але Путін не хоче цього робити. Україна буде готова зупинити удари по російських НПЗ, якщо Росія перестане наносити удари по нашій енергетичній інфраструктурі".

	 **Деталі**: Він наголосив, що будь-які деескалаційні кроки мають бути взаємними та зі справжніми гарантіями.

Водночас Зеленський нагадав, що лише за останній тиждень росіяни випустили по Україні близько 1450 авіабомб, 75 ракет різних типів та понад 1640 ударних дронів, з яких близько 60% – реактивні.
